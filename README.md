## 快速开始

本项目基于 **SDD（Spec-Driven Development）** 流程，借助 AI 编码助手进行开发。

**前置依赖：Node.js >= 20.19.0**

安装 Node.js：从 [nodejs.org](https://nodejs.org/) 下载 LTS 版本安装，验证：`node --version`

```bash
# 1. 安装 tdspeckit（全局安装，只需一次）
npm install -g tdspeckit@latest

# 2. 初始化项目（在项目目录下执行）
openspec init

# 3. 同步 AI 助手指令（将斜杠命令和技能写入 AI 工具目录）
openspec update

# 4. 在 AI 编码工具中输入斜杠命令，开始你的第一个需求
/opsx:propose "你的需求描述"
```

> 注意：第 1 步只需执行一次。如果你已执行过第 1、2 步，直接执行第 3 步同步 AI 工具指令即可。

## SDD 工作流

| 步骤 | 命令 | 说明 |
|------|------|------|
| 0. 探索思路 | `/opsx:explore` | 与新需求或问题对话，通过 AI 澄清思路、梳理方案（不写代码，纯思考） |
| 1. 提出需求 | `/opsx:propose` | 描述你想要构建的功能，AI 生成 proposal、specs、design、tasks |
| 2. 实现需求 | `/opsx:apply` | AI 按照 tasks 逐步实现代码 |
| 3. 同步规格 | `/opsx:sync` | 代码变更完成后，将 delta specs 同步回 openspec/specs/ |
| 4. 归档变更 | `/opsx:archive` | 完成后归档，specs 自动合并到主干 |

> 更详细的工作流说明请见 [docs/](docs/README.md)

## docs/ 与 openspec/ 的关系

本项目采用 **双层规范** 架构，docs/ 和 openspec/ 分工不同，协同演进：

| | docs/ | openspec/ |
|---|---|---|
| **维护者** | 人（产品、架构师） | 人 + AI 协同 |
| **内容** | 顶层规划、核心需求、架构设计 | 能力规格、变更记录 |
| **变更频率** | 低频，稳定 | 高频，每次迭代 |
| **作用** | 决策依据 | 执行和验证 |

```
  ① 立项阶段
  ┌──────────────────────────────────────────────────────┐
  │  docs/ 编写项目章程、架构设计、核心需求                  │
  └──────────────────────────┬───────────────────────────┘
                             │
                             ▼
  ② 开发迭代
  ┌──────────────────────────────────────────────────────┐
  │  /opsx:explore → propose → apply → sync → archive    │
  │  变更沉淀到 openspec/specs/                            │
  └──────────────────────────┬───────────────────────────┘
                             │
                             ▼
  ③ 阶段复盘
  ┌──────────────────────────────────────────────────────┐
  │  重要的架构变更、需求演进回写到 docs/                    │
  └──────────────────────────┬───────────────────────────┘
                             │
                             ▼
  ④ 新一轮迭代
  ┌──────────────────────────────────────────────────────┐
  │  新需求遵守 docs/ 的顶层规范                            │
  │  同时参考 openspec/specs/ 的主 spec                     │
  └──────────────────────────┬───────────────────────────┘
                             │
                             └──────────→ 回到 ②
```

**一句话总结**：docs/ 管方向，openspec/ 管执行；方向偶尔调整，执行持续迭代，两者循环进化。

## 常用命令

| 命令 | 说明 |
|------|------|
| `/opsx:explore` | 与 AI 对话探索需求和方案思路 |
| `/opsx:propose` | 描述需求，AI 生成完整变更方案 |
| `/opsx:apply` | AI 按照任务清单逐步实现代码 |
| `/opsx:archive` | 归档完成的变更到主 spec |
| `openspec list` | 查看当前活跃的变更 |
| `openspec update` | 同步斜杠命令和技能到 AI 工具目录 |
| `openspec view` | 交互式查看 specs 和 changes |
| `openspec config` | 查看和修改配置 |
