# 架构决策记录（ADR）

使用 4 位数字序号命名，格式为 `0001-<标题>.md`。

## ADR 模板

```markdown
# ADR-0001: <标题>

## 状态

Proposed（提议） | Accepted（已采纳） | Deprecated（已废弃） | Superseded（已替代）

## 上下文

描述面临的情况，包括技术、团队、业务等方面的因素。这些因素可能相互矛盾，应明确指出。

## 决策

描述做出的决策及其理由。

## 替代方案

列出曾考虑过的替代方案，以及未被采纳的原因。

## 后果

描述决策实施后的结果，列出正面和负面影响。
```
