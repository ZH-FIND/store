# 需求文档

本目录用于存放产品需求相关文档。

## 从哪里开始

创建 `01-prd.md`，描述产品的核心功能需求。参考 [openspec/specs/](../openspec/specs/) 中已有的能力规格，确保需求与现有系统一致。

示例：如果 [openspec/specs/](../openspec/specs/) 中已存在相关能力规格，你的 PRD 相关部分应该参考并对齐该 spec。

## 建议的后续文档

- `02-feature-list.md` — 按优先级排列的功能清单
- `03-non-functional.md` — 性能、安全、合规等非功能需求
- `04-user-stories.md` — 关键用户故事和验收标准

> 提示：需求写得越具体，AI 生成的 spec 和 code 越准确。
